# Project verification and operating constraints

- Use Python 3.12+ and the repository virtual environment. In Windows PowerShell, run `.\.venv\Scripts\python -m pytest tests/ -v` from the repository root. Tests must mock mutations and AssemblyAI network calls; never terminate real processes or install firewall rules for verification.
- Start the local dashboard with `.\.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000`. `/` serves the dashboard, `/static/` serves only frontend assets, and `/health` and `/api/v1/state` remain REST endpoints.
- Frontend assets are native ES modules with no build step or external libraries. Run `node --test tests/test_audio.mjs` (Node 22+). This checks PCM16 framing, little-endian samples, mixing, anti-alias filtering, resampling continuity, and reconnect timing.
- With the local server running, run `node --test tests/test_hud_browser.mjs`. This uses native CDP with a separate headless Edge profile and synthetic microphone; voice-provider and confirmation requests are intercepted in the test browser. Live telemetry stays connected to the local server. Set `VOICEOPS_BROWSER` to an alternative Chromium executable and `VOICEOPS_BASE_URL` to change the local target. No Playwright/CDN dependencies are needed.
- Microphone capture requires HTTPS or localhost and AudioWorklet support. Capture begins only after operator interaction. Browser audio is sent as 3200-byte, 100 ms, mono 16 kHz PCM16LE frames after the backend's `ready` event; stale audio is not replayed across sessions.
- This is a trusted-local-operator, single-worker service, not a multi-user authenticated deployment. Conversational memory is per voice socket; confirmation tokens are in-memory, expiring, and single-use for execution. The confirmation UI never authorizes mutations from spoken keywords or retries ambiguous execution requests.
- Network isolation currently installs host-wide outbound remote-IP firewall rules, not per-process isolation. Operational failures use `ExecutionResult.success=false` even with HTTP 200; clients must inspect that field. Partial firewall changes are reported, not automatically rolled back.
- Keep `.env` and `.venv` ignored. Never print, read into diagnostics, or commit real API keys. Provider transport logs must not expose WebSocket authorization headers or transcript payloads.
- PowerShell commands must use `;` with explicit exit-status checks rather than Bash `&&` or heredocs. Git identity is managed by the operator; do not change Git configuration.
